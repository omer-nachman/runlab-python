# runlab

This package holds the name `runlab` on PyPI. It contains no code: installing it installs
[`runlab-client`](https://pypi.org/project/runlab-client/), the Python client for the RunLab
HTTP API.

```bash
pip install runlab-client
```

```python
from runlab_client import RunLab
```

Docs, the OpenAPI spec and examples: https://github.com/omer-nachman/runlab-python
